# Reference-site research protocol

Status: promoted experimental, T3. Untested as a procedure; no reference-site study was run in this release.

Purpose: learn from existing sites without copying their implementation or
importing their claims.

## Steps

1. **Question first.** One design question per study (e.g. "how do run-log UIs
   show an approval point?"). No question, no study.
2. **Select 3–5 references** with a stated reason each. Record URL and access date.
3. **Observe rendered output** at 375px and 1280px: screenshot or accessibility
   snapshot. Separate what was observed from what is inferred.
4. **Extract principles, not assets.** Record layout logic, hierarchy, type
   roles, state behaviour. Do not copy text, imagery, code or distinctive artwork.
5. **Note licence/terms** if anything beyond observation is used (fonts, code).
6. **Write findings** with tiers; mark inference as T3.
7. **Translate** to the Bouch contract, checking against approved copy and palette.

## Tooling

Firecrawl for bounded retrieval (key from environment, never printed); one browser
MCP for rendered observation. Respect robots/terms; no authenticated areas; no bulk crawling.

## Anti-patterns

Studying many sites with no question; treating popular as good; copying a layout
wholesale; citing a site's marketing claims as fact about Bouch.
